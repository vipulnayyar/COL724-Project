- The code can be run in a P4 VM downloaded from https://github.com/p4lang/tutorials/blob/master/vm-ubuntu-24.04/README.md

- Each Sketch implementation is present in their individual folders. Their respective README.md can be followed to build and run the sketches

- The topology used for testing is as below:
```
h1 - s1 = s0 = s2 - h2
```
Their are two links between switches s0 and s1, and between s0 and s2. h1 and h2 are two hosts.
